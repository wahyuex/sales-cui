# Sales CUI

Aplikasi Manajemen Penjualan (Sales) modern, ringan, dan siap pakai.

## Fitur Utama
1. **Dashboard Utama**: Ringkasan pendapatan total, jumlah transaksi, jumlah produk, dan daftar transaksi terbaru.
2. **Manajemen Produk**: Tambah produk, atur kategori, harga, dan stok barang.
3. **Transaksi Penjualan**: Catat penjualan produk ke pelanggan dengan pemotongan stok otomatis.

## Cara Menjalankan
1. Install dependencies:
   ```bash
   npm install
   ```
2. Jalankan server:
   ```bash
   node server.js
   ```
3. Buka browser di `http://localhost:3000`
